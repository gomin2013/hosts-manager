# Changelog

## [Unreleased]

### Added

- Static UI prototype with the same layout as Git Exclude Manager: toolbar with ⚙ Settings (language en / th,
  appearance, About), `/etc/hosts` panel with search, **Add · Section · Import · Export · Restore Previous ·
  Preview Raw**, rows for entries / sections / comment blocks, and a status bar.
- Right-column **AI Agent** and **Help** panels, foldable.
- **AI Agent** (ported from Git Exclude Manager): chat about your hosts entries with Apple Foundation Models,
  Ollama, OpenAI, Gemini or Claude; Quick Messages; model menu; ⚙ AI API Settings with keys in the Keychain.
  Questions include the current `/etc/hosts`; the AI never edits the file.
- Preview Raw sheet with Copy (⇧⌘C).
- HTML reference design in `.prototype/`.
