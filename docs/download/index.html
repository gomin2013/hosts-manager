Install in three stepsติดตั้ง 3 ขั้นตอน

  1. 1. Move it to Applications1. ย้ายไปไว้ที่ Applications

    Open the .dmg and drag Hosts Manager into Applications. Run it from there, not from the disk image, so the helper can be installed.เปิดไฟล์ .dmg แล้วลาก Hosts Manager ไปที่ Applications เปิดแอปจากตรงนั้น ไม่ใช่จาก disk image เพื่อให้ติดตั้ง helper ได้

  2. 2. Allow the first launch2. อนุญาตให้เปิดครั้งแรก

    This build isn't notarized yet, so macOS blocks it once. Open System Settings, Privacy & Security, and click Open Anyway. Or run this in Terminal:build นี้ยังไม่ได้ notarize macOS จึงบล็อกครั้งแรก ให้เปิด System Settings แล้วไปที่ Privacy & Security กด Open Anyway หรือรันคำสั่งนี้ใน Terminal

    xattr -dr com.apple.quarantine "/Applications/HostsManager.app"

  3. 3. Turn on the helper3. เปิดใช้ helper

    The first time you save, macOS asks you to allow Hosts Manager in System Settings, General, Login Items & Extensions. Do it once and you're done.ครั้งแรกที่บันทึก macOS จะให้อนุญาต Hosts Manager ใน System Settings แล้วไปที่ General, Login Items & Extensions ทำครั้งเดียวก็ใช้ได้ตลอด

Build from sourceBuild จากซอร์สโค้ด

Swift Package Manager only, no Xcode project. You need Xcode 16 or the Swift 6 toolchain.ใช้ Swift Package Manager อย่างเดียว ไม่มี Xcode project ต้องมี Xcode 16 หรือ Swift 6 toolchain

git clone https://github.com/gomin2013/hosts-manager.git
cd hosts-manager
scripts/build-app.sh
cp -R build/HostsManager.app /Applications/

See theดูรายละเอียดเพิ่มเติมใน README.

Uninstallถอนการติดตั้ง

Turn the helper off in Login Items & Extensions, then move Hosts Manager to the Trash. Your /etc/hosts stays exactly as you last saved it.ปิด helper ใน Login Items & Extensions แล้วย้าย Hosts Manager ลงถังขยะ ไฟล์ /etc/hosts จะคงอยู่ตามที่บันทึกไว้ล่าสุด
